## 新增功能

本版以修复为主，没有新增面向用户的功能。

## 修复

- **Gmail / 第三方邮箱 TLS 握手失败**：全项目统一改用显式的 `SSLContext("TLS")` 并补上 `init(null, null, null)`，协议下限收到 TLS 1.2，连接时带 SNI 并显式 `startHandshake()`；IMAP 143 / SMTP 587 在升级加密前不再发送账号密码。
- **绑定验证改用实际成功的端口**：SMTP 465 被网络拦截时自动回退到 587 STARTTLS，绑定保存的是回退后真正验证通过的端口，避免「验证通过但收信失败」。
- **换机 / 重装补历史**：新设备本地为空时先分页读回服务端已归档的邮件（`/ext/mail/list`），再按本地最大 UID 续接增量，并用 `UID SEARCH SINCE` 补最近 7 天本地缺失的邮件，不再出现「换机后只剩新邮件」。
- **第三方同步状态可视**：收件箱显示「正在同步 / 从服务端补回 N 封 / 新拉取 N 封 / 没有新邮件 / 失败原因」，不再点了同步没有任何反馈。
- **窄屏固定宽度表格裁切**：表格整体超宽改为铺满视口；`td`/`th` 上的像素列宽（≥40）直接去掉交给自动布局，避免多列累加后在 360–400dp 宽度上溢出；表头只在整词放不下时才断行（修 GitHub 通知邮件 `Status` 被折成 `Sta/tus`）。

## 体验

- 绑定向导返回上一层再进来时保留已填地址与授权码（进程级草稿，不落盘）；绑定成功后立即清空授权码，离开已完成页面时重置表单。
- Gmail 提示文案改为明确区分「授权码/应用专用密码错误」与「网络拦截导致 TLS 失败」。

## 已知问题

- Gmail 仍未接入 OAuth，只能使用应用专用密码；部分网络环境访问 Google 服务器会停在 TLS/连接阶段。
- 换机补历史单轮最多读回 300 封（6 页 × 50 封），更早的缺口依赖最近 7 天的时间窗口与后续同步继续补齐。
- 第三方邮箱的已读/星标/删除仍以本地为准，不保证与 IMAP 上游即时一致。

## 安装提示

- 同签名可直接覆盖安装，登录态与本地邮件缓存保留。
- 覆盖安装后 `POST_NOTIFICATION` 等运行时权限可能被系统重置，新邮件提醒不会弹出，需要到系统设置里手动再开启。
- 回退旧版需要先卸载，本地邮件缓存会清空。

## 本版仍未经真机验证的项

- **S23 首装补历史**：换机后从服务端归档分页补回历史、以及 7 天时间窗口回补，均未在真机上跑通验证。
- **Gmail 真实 AUTH 465 / 587**：TLS 握手修复与 587 回退逻辑未在可访问 Google 服务器的真实网络下用真机验证；当前验证仅为代码与单元测试层面。
- **窄屏 360–400dp 表格自适应**：`normalizeFixedWidths` 的列宽清洗与表头折行未在真机/模拟器窄屏下逐一复验。
