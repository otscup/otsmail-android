## 新增功能

- 本版没有新增面向用户的功能。

## 修复

- **第三方邮件详情页正文铺满屏宽**：IMAP/SMTP 账户的正文区此前是 20dp 内边距 + 灰色页面底，两侧灰边让正文看起来比普通邮件窄；现在改为白底铺满屏宽、内容左右各 16dp，与普通邮件详情一致。
- **常规邮件同步改为静默后台拉取**：启动、IDLE 唤醒与后台定时同步不再显示「正在同步…」状态条，也不再弹第三方同步失败提示条。
  - 只有用户主动下拉刷新或点「立即同步」时才显示本轮同步状态，结束或失败后 8 秒自动收起。
  - 后台同步失败不再静默消失：进入「设置 → 外部邮箱」可看到每个账户的上次同步时间与失败原因。
- **AI 消息操作改为点击出现图标**：每条 AI 输出下方的「复制」「回复」文字按钮改为图标，只有点击该条消息时才出现，同一时刻只展开一条；点其他消息切换、点别处或再点一次收起。图标点击区域 40dp。复制与回复行为不变。

## 已知问题

- 非 Google Play 渠道（直接安装 GitHub Release 里的 APK）仍可能触发 Play 保护机制的应用扫描或提示，这是系统对侧载应用的常规行为，不代表安装包损坏。
- Android 13 及以下，系统层面只有 Google 密码管理器可作为凭据提供方，app 内通行密钥无法保存到 Bitwarden 等第三方密码管理器；这类密码管理器需走浏览器完成通行密钥流程。这是系统限制，不是本 App 的缺陷。
- 通行密钥依赖 GMS；无 GMS 设备不可用。
- 端到端加密目前只提供本机密钥对的查看、导出与重建，加密发送与接收解密尚未生效。
- 第三方邮箱同步失败只在「设置 → 外部邮箱」里可查，收件箱不再提示；需要主动进设置确认。
- 「回复」生成的草稿不带收件人和主题，需要用户在写信页自行补全。

## 安装提示

- 同签名可直接覆盖安装，登录态与本地邮件缓存保留。
- 覆盖安装会重置通知权限（`POST_NOTIFICATION` 回到 ignore），装完需到系统设置里手动重新开启一次，否则新邮件提醒与稍后提醒都不会弹出。
- 回退旧版需要先卸载，本地邮件缓存会清空。

## 本版仍未经真机验证的项
