## 新增功能

- **两步验证内置验证器**：「设置 → 安全 → 身份验证器」可直接出 6 位验证码，不用再开别的 App。
  - 开启两步验证成功后，密钥自动写入本机（Android Keystore AES-256/GCM 加密，按登录邮箱分条存放），当场就能出码。
  - 老用户可在同一页「导入密钥」：粘贴 base32 密钥 / `otpauth://` 链接，或「扫码导入」直接扫 otpauth 二维码。
  - 验证器丢了可「重新绑定」：先用旧验证码或一枚备用码确认身份，服务端签发新密钥；新验证器出码确认后原子切换，完成前旧密钥仍可用。
  - 「移除验证器」只清本机密钥，不会关闭账号的两步验证；删除账号时会一并清理本机密钥。退出登录不删除，换号回来仍可出码。
- **两步验证备用码**：「设置 → 安全 → 备用码」显示剩余数量（如 `剩余 8/10`），可输入当前密码或验证器验证码生成/重新生成；明文只展示一次，重新生成会让旧备用码整批失效。
- **登录页支持备用码**：两步验证步骤新增「验证器丢了？改用备用码」切换，输入框按 10 位备用码（`XXXXX-XXXXX`）接受字母数字，可随时切回验证码。
- **关闭两步验证支持备用码**：输入当前验证器的 6 位验证码，或一枚未使用的备用码即可关闭；不再把输入当登录密码提交。
- **系统设置新增「发信渠道」页**（需 `setting:set` 权限，默认管理员）：「设置 → 系统设置 → 发信」进入，与网页端「系统设置 → 发信渠道」同一套接口。
  - 顶部汇总已同步渠道数、参与轮换数、今日/本月剩余与已用额度。
  - 每个渠道可展开填 API Key / Secret、日限额 / 月限额（留空跟随默认值）、启用开关；保存后立即参与轮换。
  - 支持单渠道「测试发送」、DoH「核验 DNS」（含 SPF 状态）、跳转渠道注册页，并标出「已同步 / 未同步 / 冷却中」。

## 修复

- 扫码页支持「任意二维码」模式：从验证器页进入扫码只把原始文本回传用于导入 otpauth 密钥，不再按网页登录二维码解析；网页登录扫码行为不变。
- 两步验证状态接口改为结构化解析，可带回备用码总数与剩余数；设置页展示的剩余数量与服务端一致。
- 删除账号时同步清理本机验证器密钥，避免下一个账号看到上一账号的空绑定记录。

## 已知问题

- 备用码与发信渠道依赖服务端同批接口（`/my/2fa/backup-codes`、`/my/2fa/rebind/*`、`/setting/senderProviders`）；服务端未升级时，这两处会提示读取或生成失败。
- 发信渠道的用量是本站按自然日（UTC）统计的真实发送数；各服务商后台额度没有开放查询接口，仍需到其控制台查看。
- 本机验证器密钥随卸载或「清除数据」一起消失。卸载前请确认还有别的验证器或已保存的备用码，否则会登不进去。
- 「移除本机验证器」只影响本机，不会关闭账号的两步验证；共享设备换人使用前请手动移除。
- 非 Google Play 渠道（直接安装 GitHub Release 里的 APK）仍可能触发 Play 保护机制的应用扫描或提示，这是系统对侧载应用的常规行为，不代表安装包损坏。
- 通行密钥依赖 GMS，无 GMS 设备不可用；Android 13 及以下 app 内通行密钥无法保存到 Bitwarden 等第三方密码管理器，需走浏览器完成流程。
- 端到端加密目前只提供本机密钥对的查看、导出与重建，加密发送与接收解密尚未生效。

## 安装提示

- 同签名可直接覆盖安装，登录态、本机验证器密钥与本地邮件缓存保留。
- 覆盖安装会重置通知权限（`POST_NOTIFICATION` 回到 ignore），装完需到系统设置里手动重新开启一次，否则新邮件提醒与稍后提醒都不会弹出。
- 回退旧版需要先卸载，本地邮件缓存与本机验证器密钥会清空。

## 本版仍未经真机验证的项

- 发布时只完成编译与本地签名构建验证，未在真机上安装过本版 APK。以下两块是本版新增、但没有真机跑过的：
  - **两步验证内置验证器**：出码与倒计时、开启 2FA 自动写入本机、粘贴/扫码导入、重新绑定全流程、移除本机验证器、删除账号时清理；以及登录页备用码切换与关闭 2FA 的备用码分支。
  - **发信渠道页**：读取/保存渠道、单渠道测试发送、DNS 核验、额度汇总与剩余计算。
- 验证器出码与服务器时间偏差（设备时间不准时的验证码失败）未实测。
- 平板/折叠屏下新增页面的布局未验证。
