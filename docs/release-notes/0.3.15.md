## 新增功能

- 本版没有新增面向用户的功能。

## 修复

- **邮件正文宽版面不再被居中推移**：营销邮件常把版面写死成 600px，再用 `align="center"` 或 `margin:0 auto` 居中。阅读区比版面宽时，整块正文会右移（阅读区宽 − 版面宽）÷ 2，和贴左的表头 Logo 错开。现按网页端与服务端同一套规则、同一阈值（≥360px）补上版面级居中归一化，并在固定宽度归一化之前执行（否则 600px 已先被改成 100%，规则永远不触发）。
  - 只去掉「承载宽版面的单元格」和「宽版面自身」的居中，版面宽度本身不变；200px 按钮、卡片这类小尺寸居中保持原样。
  - 样式禁令、`on*` 事件清理与链接协议白名单策略均未放宽。
- **正文图片不再因客户端超时过早显示失败**：正文图片由服务端签名代理取图，代理侧上游超时是 10s 还要加 DoH 校验；客户端原先 6s 读超时会先放弃，把其实已经取到的图显示成「图片加载失败」占位。读超时已放宽到 15s，覆盖服务端的超时预算。

## 已知问题

- 正文图片仍依赖服务端图片代理；代理侧本身超时、签名过期（`exp`）或上游 4xx/5xx 时，依旧会显示「图片加载失败」占位。
- 弱网或代理慢响应下，取图最长要等到 15 秒才落到失败占位，等待期间显示加载状态。
- 非 Google Play 渠道（直接安装 GitHub Release 里的 APK）仍可能触发 Play 保护机制的应用扫描或提示，这是系统对侧载应用的常规行为，不代表安装包损坏。
- 通行密钥依赖 GMS，无 GMS 设备不可用；Android 13 及以下 app 内通行密钥无法保存到 Bitwarden 等第三方密码管理器，需走浏览器完成流程。
- 端到端加密目前只提供本机密钥对的查看、导出与重建，加密发送与接收解密尚未生效。
- 两步验证内置验证器与「发信渠道」页仍是 0.3.12 引入的功能，依赖服务端同批接口；服务端未升级时这两处会提示读取或生成失败。

## 安装提示

- 同签名可直接覆盖安装，登录态、本机验证器密钥与本地邮件缓存保留。
- 覆盖安装会重置通知权限（`POST_NOTIFICATION` 回到 ignore），装完需到系统设置里手动重新开启一次，否则新邮件提醒与稍后提醒都不会弹出。
- 回退旧版需要先卸载，本地邮件缓存与本机验证器密钥会清空。

## 本版仍未经真机验证的项

- 正文版面级居中与图片 15s 读超时**均未在真机上验证**。发布前只完成编译与本地单测（`EmailHtmlSanitizerTest`，含新增的宽版面去居中与代理地址保留用例）。
- 未在真机上用真实营销邮件（600px 版面 + 居中单元格 + 打码表头 Logo）核对细节页的实际对齐效果。
- 未在弱网 / 代理慢响应场景下验证图片等待 15 秒期间的表现，也未验证超时后占位的最终状态。
- 平板 / 折叠屏宽阅读区下的对齐表现未验证。
