## 新增功能

- **扫码登录**：网页端生成二维码 → App 内扫码并确认 → 网页端完成登录。入口在「个人设置 → 扫一扫」，也可长按桌面图标选择「扫一扫」；未登录时会先引导登录再继续扫码。
- **验证码一键识别与复制**：邮件正文里识别到验证码时，详情页顶部出现「复制验证码」；通知栏与弹窗提醒（heads-up）上提供「复制验证码」按钮，不用先打开 App。识别只认验证码类关键词附近的短数字，订单号、快递单号、金额、日期、手机号等不会误判。

## 变更

- **第三方邮件提醒改为「保持长连接（第三方邮件提醒）」开关**（外部邮箱设置页）：
  - 开：第三方邮箱走 IMAP IDLE，收到新邮件立即提醒（即原来「自动 / 始终用长连接」的行为）；
  - 关：停掉 IDLE 服务，不连长连接、不启动 15 分钟轮询兜底、不弹第三方通知；收件箱手动同步与下拉刷新照旧。
  - 原「自动 / 始终用长连接 / 只用设备推送（调试）」三选一已删除，不再保留并存的调试项。
  - 存量值兼容：`auto` / `idle` 读作开；`fcm`（旧的「只用设备推送（调试）」，实际收不到提醒）读作关；未设置或未知值读作开。
- otsmail 自身邮件的 FCM 推送在任何开关状态下都不受影响：不注销 token、不改登记、不干扰站内通知。

## 修复

本版以新增功能与设置语义修正为主，没有单独的缺陷修复项。

## 已知问题

- **扫码端到端未验证**：依赖服务端先部署 `/login/qr` 与 `/my/qr/confirm`（当前线上可能 404）；服务端未部署时网页取码与 App 确认都会失败。
- 服务端 confirm 不返回发起方 IP/UA，App 的确认框只能显示通用文案，用户无法核对来源设备与位置。

## 安装提示

- 同签名可直接覆盖安装，登录态与本地邮件缓存保留。
- **覆盖安装会重置通知权限**（`POST_NOTIFICATION` 的 app-op 回到 ignore），装完需要到系统设置里手动再开启一次，否则新邮件提醒不会弹出。
- 回退旧版需要先卸载，本地邮件缓存会清空。

## 本版仍未经真机验证的项

- **扫码登录端到端**：未在服务端部署完成后跑通「网页出码 → App 扫码确认 → 网页登录」全链路。
- **相机表现**：真机相机预览方向、对焦、暗光下的识别成功率未验证。
- **桌面快捷方式**：「长按图标 → 扫一扫」未在真实启动器上确认。
- **通知栏复制**：复制 action 在锁屏与通知折叠态下的可见性、可点击性未验证。
- **关闭提醒后的服务停止**：开关拨到关后 `ExtIdleService` 停止、轮询兜底不再启动，目前只做了代码层确认，未在真机上观察功耗与通知残留。
