## 新增功能

- **稍后提醒**：详情页可把邮件「稍后提醒」，到点通过通知栏提醒，列表页集中管理；开机、装包、改时间、改时区后会自动重新排程，不会丢提醒。
- **会话（会话线程）视图**：同一主题的往来邮件按会话聚合查看。
- **一键退订**：识别邮件里的退订方式（`List-Unsubscribe` 等）并提供退订入口。
- **通行密钥（Passkey）**：支持用系统凭据管理器创建/使用通行密钥登录，替代或补充密码登录；设备不支持时给出明确原因。
- **端到端加密（E2EE）设置页**：展示本机密钥指纹与公钥，支持生成/重建密钥对。
- **日历邀请（.ics）解析**：解析邮件附件中的日历邀请信息，为后续日程能力打底。
- **VIP 联系人**：可标记 VIP 联系人，用于区分重要来信。
- **外部邮箱可见性设置**：控制第三方邮箱邮件在统一列表中的展示范围。
- **设置页新增「辅助安全邮箱」**：用于账户找回的辅助邮箱配置。

## 已知问题

- 本版新增功能（稍后提醒、会话、退订、通行密钥、E2EE、VIP 联系人、日历解析）目前只完成代码与单元测试，尚未在真机走通完整链路；服务端接口是否已全部上线未在本机核验。
- 通行密钥依赖服务端 `assetlinks.json` 域名关联；若服务端未配置或签名不匹配，客户端会提示「服务器未完成通行密钥域名关联」，此时不可用。
- 第三方邮箱链路仍不支持「移动到分类」「翻译 / AI 摘要 / 智能回复」「标记为垃圾邮件」，界面上已置灰并说明原因。
- 日历 `.ics` 目前只做解析，未提供日程写入系统日历的完整流程。

## 安装提示

- 同签名可直接覆盖安装，登录态与本地邮件缓存保留。
- 覆盖安装会重置通知权限（`POST_NOTIFICATION` 回到 ignore），装完需到系统设置里手动重新开启一次，否则新邮件提醒与稍后提醒都不会弹出。
- 稍后提醒依赖精确闹钟与开机广播，部分厂商系统的省电策略可能延后或拦截，建议把本 App 加入电池优化白名单。
- 回退旧版需要先卸载，本地邮件缓存会清空。
