## 新增功能

本版没有新增面向用户的功能。

## 修复

- **登录页第三方登录按钮不再「晚一步」出现**：GitHub / Google / LinuxDo / 企业 SSO 这些按钮的显示与否，取决于 `/setting/websiteConfig` 里的开关。之前必须等这份网络配置回来才开始渲染，于是账号密码区先出来、按钮隔一会儿才冒出来，底部还会先空一块。
  - 现在按服务器地址把最后一次成功的站点配置缓存在本机，冷启动首帧就按缓存把按钮画在正确位置，网络回来后再静默刷新。
  - 首次安装、还没有缓存时，先用两个等高的按钮位置（含「或」分隔线）占位，配置到达后就地替换，不再出现「先空一块再跳出来」。
  - 在登录页右上角切换服务器时，会立即改用新服务器自己的缓存，不会把上一台的第三方登录方式带过来。

## 已知问题

- 非 Google Play 渠道（直接安装 GitHub Release 里的 APK）仍可能触发 Play 保护机制的应用扫描或提示，这是系统对侧载应用的常规行为，不代表安装包损坏。
- Android 13 及以下，系统层面只有 Google 密码管理器可作为凭据提供方，app 内通行密钥无法保存到 Bitwarden 等第三方密码管理器；这类密码管理器需走浏览器完成通行密钥流程。这是系统限制，不是本 App 的缺陷。
- 通行密钥依赖 GMS；无 GMS 设备不可用。
- 站点配置缓存保存的是「最后一次成功结果」：服务端刚调整过第三方登录开关时，登录页可能先显示旧按钮，待本次刷新完成后自动纠正；若刷新失败则保持旧结果。

## 安装提示

- 同签名可直接覆盖安装，登录态与本地邮件缓存保留。
- 覆盖安装会重置通知权限（`POST_NOTIFICATION` 回到 ignore），装完需到系统设置里手动重新开启一次，否则新邮件提醒与稍后提醒都不会弹出。
- 回退旧版需要先卸载，本地邮件缓存会清空。

## 本版仍未经真机验证的项

- **登录页第三方登录按钮的缓存首帧与占位高度仅通过编译验证**：未在真机、弱网（高延迟）与断网场景下实测观感。
- 占位按常见的两个第三方入口预留高度；服务端开启的入口数量明显不同（如 0 个或 3 个以上）时，可能出现一次轻微的高度变化。
